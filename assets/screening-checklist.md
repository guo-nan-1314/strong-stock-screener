# 强势股筛选自查清单

> 筛选出强势股后，用以下清单做二次验证

## 一、基本面快查

- [ ] 是否为 ST / *ST 股票（风险警示）
- [ ] 近期是否有重大利空公告（减持/亏损/违规）
- [ ] 所属行业是否为当前市场热点

## 二、技术面验证

- [ ] 成交量是否有效放大（非对倒放量）
- [ ] 是否突破关键阻力位
- [ ] 均线系统是否多头排列（MA5 > MA10 > MA20）
- [ ] MACD 是否在零轴上方金叉

## 三、资金面确认

- [ ] 主力资金是否持续净流入
- [ ] 北向资金是否同步买入（如适用）
- [ ] 龙虎榜是否有机构席位（如上榜）

## 四、风险提示

- [ ] 是否已经连续大涨（追高风险）
- [ ] 换手率是否过高（>20% 需警惕）
- [ ] 大盘环境是否配合（系统性风险）
